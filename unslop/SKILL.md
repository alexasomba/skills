# Optional prose cleanup

Use only when requested or clearly useful for prose. Never rewrite source code,
commands, identifiers, paths, configuration keys, code comments that carry exact
technical instructions, quotes, test names, or exact error text. Preserve meaning and
the author's tone. This skill is not a commit, PR, or message requirement.
