# Promotion review helper

Use only with an explicit user instruction and only for the `preview` to `main`
promotion PR. Read checks and comments, summarize actionable findings locally, and
link evidence. Do not push, edit PRs, trigger Greptile, resolve threads, or repeat a
review loop. Those are external writes and need separate explicit instructions.
