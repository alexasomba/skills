# Optional prose quality pass

Apply prose cleanup only when it improves human-facing text. Prefer concrete
claims, varied natural rhythm, and the shortest wording that preserves meaning.
Remove filler, puffery, repetition, vague attribution, canned transitions, and
unnecessary headings.

Never rewrite code, commands, paths, identifiers, API names, error messages,
quoted material, test fixtures, generated files, or exact technical text. Prose
cleanup is optional and cannot block verification or alter behavior.
